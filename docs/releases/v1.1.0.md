# @mdab25/ksef-pdf v1.1.0

This minor release imports CIRFMF/ksef-pdf-generator 1.1.40, including releases
1.1.36 and 1.1.39 since our previous 1.1.31 baseline. Existing 1.0.x callers do
not need to migrate; Node.js 22 or newer is still required.

## Upstream changes

- **1.1.36:** pdfmake update, already covered by this package's 0.3.11 dependency.
- **1.1.39:** initial PEF support, typed translations, corrected UPO document-parts
  wording, transaction exchange-rate currency formatting, and disabled debug output.
- **1.1.40:** production PEF layouts, UTF-16 XML input, and spacing after the KSeF
  number label. The source diff also fixes other-cargo descriptions for FA(1/2/3).

PEF basic, corrective, and specialized XML documents now work with
`renderPdfFromXml`, `renderPdfBase64FromXml`, and `generateInvoice`.
`detectPefInvoiceVersion` and the low-level `generateBasicPEF`,
`generateCorrectivePEF`, and `generateSpecPEF` functions are new exports.
See the [README](../../README.md) for the supported profiles.

UTF-8 and UTF-16 LE/BE are decoded for `Uint8Array` (including Node buffers),
`ArrayBuffer`, `Blob`, and `File` inputs. UTF-16 is recognized by its BOM or XML
opening bytes. Already-decoded strings continue to work as before.

## Compatibility

- Existing FA/UPO exports, return formats, and the FA-only `KsefInvoiceVersion`
  type are preserved. PEF uses a separate detection helper and type.
- The local Node adapters, virtual fonts, deny-by-default resource policies,
  watermark exclusion, QR1/QR2, KSeF metadata, and deterministic Warsaw timestamps
  are retained. New PEF footers identify this package too.
- Runtime dependencies and the minimum Node version are unchanged. Upstream's
  browser application and toolchain dependencies are not imported.
- PEF adds a unit-code dictionary and schema types, increasing the bundle and
  declaration size. No additional runtime dependency is required.

## Validation

All 1,026 tests in 135 files passed on Node 22.23.3 and Node 24.20.0. The Node 22
run also used `America/Los_Angeles` to exercise host-timezone independence.
The upstream unit suite and package regression tests cover FA/UPO behavior, PEF
content and correction amounts, output formats, native Node inputs, UTF-16
endianness and BOM handling, Polish text, QR metadata, and the transport fix.
Typechecking, ESM/CJS builds, all 16 runtime export checks, documentation and
release consistency checks, and package inspection passed. npm audit reported
zero vulnerabilities. Both built module formats rendered all seven invoice
layouts and both UPO versions on Node 22 and 24.

The packed npm artifact was installed in an isolated consumer directory. The
unchanged KSeF Canvas renderer CLI successfully rendered Canvas's synthetic
release fixture, a multi-page invoice, and UPO on Node 22 and 24. Canvas's
dependency pin was not changed by this library release preparation.

Before/after rendering of the six existing document formats preserves page
counts and extracted content except for the intended KSeF-label spacing and
package-version footer. These fixture checks do not exhaust every possible
invoice layout.

The exact imported commit is recorded in [UPSTREAM.md](../../UPSTREAM.md).
