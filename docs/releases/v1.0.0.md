# @mdab25/ksef-pdf v1.0.0

Version 1.0.0 moves the package to Node.js 22+, synchronizes the renderer with
CIRFMF 1.1.31, and upgrades pdfmake to its Promise-based 0.3 API.

Highlights:

- FA_RR(1), QR2, KSeF acquisition date, and custom virtual fonts.
- Current CIRFMF invoice formatting, correction, attachment, and pagination fixes.
- Preserved high-level rendering APIs and ESM/CJS entry points.
- Package-owned version footer and no TEST/DEMO watermark.
- Full upstream test suite plus API, release, package, and visual checks.

Node 20 and callback calls on low-level `generateFA*` PDF objects are breaking
changes. See [the migration guide](../migration-to-1.0.md) before upgrading.
