# @mdab25/ksef-pdf v1.1.2

This metadata and documentation patch release links the package to its
maintainer's site and refreshes development tooling. No migration from 1.1.1 is
required. Node.js 22+ and the CIRFMF 1.1.40 renderer baseline remain unchanged.

## Changes

- The `author` field in `package.json` names Mateusz Dąbrowski and links to
  [mdab.it](https://mdab.it).
- The README support section links to the
  [KSeF invoice automation case study](https://mdab.it/en/case-studies/invoice-automation/),
  a production workflow that renders its invoice PDFs with this package.
- Development dependencies (vitest, vite, and source-map-js through tsup) were
  updated to clear new `npm audit` advisories. The production dependency tree is
  unchanged.

## Compatibility

Runtime source, exports, dependencies, and supported formats are unchanged.
Generated invoice footers display package version 1.1.2, so generated PDFs
should not be compared byte-for-byte with 1.1.1.

## Validation

- Typechecking, all 1,026 tests, ESM/CJS builds, and the runtime export checks
  (all seven invoice layouts and both UPO versions through both module formats)
  passed.
- `npm audit` reports no vulnerabilities; documentation link and release
  metadata checks passed.

See the [README](../../README.md) for usage and the [changelog](../../CHANGELOG.md)
for release history.
