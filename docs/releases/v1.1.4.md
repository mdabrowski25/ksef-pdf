# @mdab25/ksef-pdf v1.1.4

This patch release corrects the caption printed under the first QR code. No
migration from 1.1.x is required.

## Changes

- The QR1 caption is now the KSeF number whenever `nrKSeF` is supplied, and
  `OFFLINE` otherwise. Earlier versions printed `OFFLINE` whenever `qr2Code` was
  present, so an offline invoice already accepted by KSeF was labelled as if it
  had not been sent.
- An invoice with a QR1 link but no KSeF number now shows `OFFLINE`. Earlier
  versions left the caption empty unless `qr2Code` was present. This matches the
  KSeF rule for online invoices still waiting for their number.
- The change applies to FA(1), FA(2), FA(3), FA_RR(1), and PEF layouts. The QR2
  section and its `CERTYFIKAT` caption are unchanged.

## Upstream difference

CIRFMF 1.1.46 still chooses the caption from `qr2Code`. This release deliberately
differs from it, following the
[KSeF QR code documentation](https://github.com/CIRFMF/ksef-docs/blob/main/kody-qr.md).
The difference is recorded in `UPSTREAM.md` and must be kept across future
synchronizations.

Applications must update their pinned dependency and deploy the resulting build
to receive the fix. Previously generated or cached PDFs remain unchanged unless
the application explicitly regenerates them.
